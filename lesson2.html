The Transformer Architecture

Complete architectural breakdown with symbolic notation and data flow

The transformer is a remarkable piece of algorithmic engineering: a stack of identical layers, each built from just two sub-components (self-attention + feed-forward network), organized with residual connections and layer normalization. It has no recurrence, no convolution — just matrix multiplications and a softmax. Yet from this simple recipe, models like GPT-4 exhibit reasoning, creativity, and chain-of-thought. Let's understand exactly how.
TL;DR

The transformer layer is: output = LayerNorm(x + FFN(LayerNorm(x + Attention(x)))). Attention allows all tokens to communicate pairwise. The FFN processes each token independently. LayerNorm stabilizes training. Residual connections enable deep stacks. Stack N layers, predict the next token, and you have an LLM.

Scaled Dot-Product Attention

Attention is the core innovation. Each token computes how much to focus on every other token:

Scaled Dot-Product Attention
Q = X · WQ   K = X · WK   V = X · WV

Attention(Q, K, V) = softmax( QKT / √dk ) · V

Where:
X ∈ ℝn×d — input of n tokens, each d-dimensional
WQ, WK ∈ ℝd×dk — query/key projection matrices
WV ∈ ℝd×dv — value projection matrix
dk — dimension of keys (typically d / n_heads)

Step-by-step, attention computes:

  1. Project input into Q, K, V spaces via learned weight matrices
  2. Score — compute dot products QKT: each token asks "how relevant is everyone else to me?"
  3. Scale by √dk — prevents softmax from saturating to 0/1 for large dk
  4. Softmax over the last dimension — converts scores to probabilities summing to 1
  5. Weighted sum — multiply by V: each token's output is a weighted blend of all value vectors
The scaling factor √dk is crucial. Without it, for large dk, the dot products grow large, pushing softmax into regions with extremely small gradients — making training unstable or impossible.

Causal (Masked) Attention

In decoder-only autoregressive models (GPT, LLaMA, etc.), attention must be causal — tokens can only attend to themselves and earlier tokens. This is implemented by applying a mask before softmax:

score(i, j) = qi · kj + Mij,   Mij = 0 if j ≤ i, else −∞

Adding −∞ ensures the softmax output for future positions is zero — the model never sees tokens it hasn't generated yet.

Multi-Head Attention

Instead of a single attention operation, transformers run h parallel attention "heads", each with its own Q, K, V projections. The outputs are concatenated and projected again:

Multi-Head Attention
headi = Attention(XWQ,i, XWK,i, XWV,i)

MultiHead(X) = Concat(head1, ..., headh) · WO

Where each headi produces dk-dimensional output,
and WO ∈ ℝh·dk × d is the output projection.

Total dimension: dk = d / h (typically)

Different heads learn different attention patterns — some focus on syntax, others on semantics, others on position. With 32 heads, a 7B model has 32 different "views" of the input sequence simultaneously.

Feed-Forward Network

Applied identically to each position. The FFN is a two-layer MLP with a hidden dimension typically 3-4× the model dimension:

Feed-Forward Network (SwiGLU variant, used in LLaMA)
FFN(x) = (σ(x · Wgate) ⊙ (x · Wup)) · Wdown

Where:
Wgate, Wup ∈ ℝd×dff — gate and up projections
Wdown ∈ ℝdff×d — down projection
σ = Swish/SiLU activation: σ(x) = x · sigmoid(x)
⊙ = element-wise multiplication
dff typically = 3.5 · d (varies by model)

The FFN stores factual knowledge — it's where the model "remembers" that Paris is the capital of France. Self-attention decides which tokens to retrieve information from; the FFN provides the information itself.

Layer Normalization

Applied before each sub-layer (pre-norm, the modern convention — unlike the original post-norm transformer):

Layer Normalization
LayerNorm(x) = γ ⊙ (x − μ) / σ + β

Where:
μ = (1/d) Σi xi   (mean across features)
σ = √((1/d) Σi (xi - μ)² + ε)   (stddev across features)
γ, β ∈ ℝd — learnable affine parameters
ε — small constant for numerical stability (~10⁻⁵)

LayerNorm stabilizes training by ensuring activations have zero mean and unit variance, regardless of the input scale. RMS Norm (used in LLaMA) is a simplified variant that only normalizes by the root-mean-square, omitting mean subtraction.

Residual Connections

Each sub-layer is wrapped in a residual connection that adds the input back to the output:

xℓ+1 = xℓ + Sublayer(LayerNorm(xℓ))

Residual connections are the reason we can stack 80+ layers (like in GPT-4). Without them, gradients would vanish as they propagate back through the network. The residual path provides a "gradient highway" from the output to the input.

Encoder vs Decoder vs Encoder-Decoder

ArchitectureExample ModelsAttention TypeUse Case
Encoder-onlyBERT, RoBERTaBidirectional (full)Classification, NER, embedding
Decoder-onlyGPT, LLaMA, MistralCausal (masked)Text generation (most modern LLMs)
Encoder-DecoderT5, BARTCausal + cross-attnTranslation, summarization

Most modern LLMs (GPT-4, Claude, Gemini, LLaMA) use decoder-only architectures. The decoder processes tokens causally (left-to-right) and generates text autoregressively. The encoder-decoder architecture (T5, BART) uses an encoder with full bidirectional attention to process the input, then a decoder with causal attention + cross-attention to the encoder output to generate.

Parameter Accounting

For a typical decoder-only transformer with d = 4096 (7B-scale):

ComponentShapeParametersFraction
Token EmbeddingV × d~500M (V=128k)~7%
Q/K/V projections (per layer)3 × d × d50M × 32 = 1.6B~23%
Output projection (per layer)d × d17M × 32 = 0.5B~7%
FFN gate/up (per layer)2 × d × dff114M × 32 = 3.6B~52%
FFN down (per layer)dff × d57M × 32 = 1.8B~26%
LayerNorm (per layer)2 × d8k × 32 = 0.3Mnegligible
Key insight: The FFN accounts for ~2/3 of parameters in most transformers. Attention is expensive in FLOPs (O(L²)) but relatively cheap in parameters. Scaling the FFN hidden dimension is the most parameter-efficient way to increase model capacity.

Summary

  • Transformer block: LN(x + MHA(LN(x))) → LN(x + FFN(LN(x)))
  • Self-attention enables all-to-all token communication with O(L²) cost
  • Multi-head gives the model multiple parallel views of relationships
  • FFN stores factual knowledge, processes each token independently
  • LayerNorm + residual connections enable stable training at depth
  • Modern LLMs use decoder-only architecture with causal attention
